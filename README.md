# Mac Price Radar — единая таблица цен

Одна большая таблица публичных цен российских магазинов с поиском и фильтрами. Конфигурации MacBook расположены в строках, магазины — в столбцах. Закупки, себестоимость, заказы и другие бизнес-функции будут надстраиваться позже.

Исходные бизнес-требования: [requirements.md](requirements.md). Текущий приоритет и состояние серверных модулей: [IMPLEMENTATION.md](IMPLEMENTATION.md).

Отдельный сайт заказов «Макбучная» для `order.macbookbro.ru`: [описание и запуск](order-site/README.md). Локальный просмотр: `npm run dev:orders`, проверки: `npm run test:orders`. Сервис и база заказов отделены от парсера цен.

Обновление 27.09.2026 опубликовано на обоих доменах: быстрый поиск, ссылки на подборки и конфигурации, мобильная панель заказа и повтор расчёта при сбое. [Проверки и откат](docs/usability-2026-09-27.md).

## Доступ к серверу и публикация

На текущем Mac подключение: `ssh macbookbro`. [Пошаговая инструкция, карта сервисов и просмотр журналов](docs/server-access.md). Для входа двойным щелчком есть `scripts/connect-server.command`. «Залей» означает проверку, коммит, пуш, публикацию в нужном окружении и проверку работающего сайта.

## Запуск

Требуется Node.js 22.13+ с `node:sqlite` (проверено на Node 24).

```bash
npm install
npm run build:data
npm run dev
```

Откройте <http://127.0.0.1:4173/web/>. Для текущего компьютера без Node в PATH:

```bash
/Users/max/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node scripts/build-data.mjs
/Users/max/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node scripts/server.mjs
```

Первый `build:data` сохраняет исходный `data/cheapest.json` в `data/private/backups/` и переносит реальные наблюдения в `data/private/master.sqlite`. Демонстрационные примеры исключаются. Без `LIVE=1` сеть не опрашивается: пересчитывается представление сохранённой базы.

## Работа с таблицей

- На первом экране видны закупочные каналы и отдельные колонки всех соседних магазинов НН. Москва и Авито находятся дальше справа.
- Цвета и несовместимые комплектации показаны отдельными строками. Повторные наблюдения одной карточки удаляются; новая цена заменяет старую, даже если она выросла. Пропущенные характеристики объединяются только при однозначном совпадении.
- Поиск понимает модель, артикул, процессор, память, накопитель и название источника. Дополнительные параметры находятся в блоке «Уточнить процессор, память и цвет».
- Зелёным выделена минимальная актуальная цена среди магазинов НН в строке. После модели восстановлен блок «Ритейл-аналитика»: минимальная свежая закупка, средняя свежих цен НН, разница в рублях и процентах к закупке, рекомендация продажи. Разница использует именно показанную среднюю; без свежей закупки или розничного ориентира она остаётся пустой. В среднюю входит по одной цене каждого магазина. Закупка, Москва и Авито в среднюю не входят. Рядом сохранена рекомендация продажи: на 500 ₽ ниже минимальной сопоставимой цены доверенного магазина НН.
- Страницы по 30 строк, кэш ответов и gzip уменьшают начальную загрузку. Неизменившийся снимок повторно не загружается и не отрисовывается. Экспорт включает все строки выбранного фильтра.
- У ReSale нет постоянной пониженной оценки доверия: для всех магазинов действуют общие правила. Вместо «Нужно проверить» бейдж показывает причину и отклонение, например «Ниже рынка на ~8%» или «Этот цвет дешевле другого на ~3,6%». Наведение показывает цену ориентира.
- Новые Telegram-каналы из пересланных текстовых прайсов автоматически получают отдельные колонки с названием канала. Числовой ID сохраняет источник при переименовании и различает каналы с одинаковыми названиями. Прайс запускает разбор через webhook или polling без ожидания почасового обновления.

Интерфейс `dev.macbookbro.ru` использует светлое оформление, системный шрифт, карточки моделей и адаптивную таблицу. Шапка убрана. Один блок объединяет состояние сбора, фактический возраст закупочных цен, почасовое расписание и кнопку «Обновить цены». Даты прайсов и время следующей проверки отображаются по Москве; смешанные даты не выдаются за вчерашние. Сайт имеет favicon-набор, Open Graph-картинку, `robots.txt`, `sitemap.xml`, свою 404-страницу и обезличенную first-party аналитику. События без IP-адресов пишутся в закрытый `data/private/analytics.ndjson` и не попадают в репозиторий.

Сводная строка объединяет модель, диагональ, чип, RAM и SSD. Внутри сохранены отдельные варианты цвета, CPU/GPU, состояния, клавиатуры и региона; исходные наблюдения в базе не удаляются. Для расчёта известные несовпадения не смешиваются. Пропущенные характеристики позволяют только предварительную оценку, если наблюдаемые варианты не противоречат друг другу; такая оценка явно помечается. Если возможны разные CPU/GPU, цена с неизвестными ядрами к ним не привязывается.

Все цены в таблице — в рублях. Отсутствие валюты в разметке магазина не отклоняет цену. Старые цены остаются видимыми с отметкой «Старая проверка» после четырёх часов. Неизвестное наличие показывается отдельно. Время каждой цены доступно в подсказке в часовом поясе браузера. Просроченные, отклонённые и недоступные предложения, рассрочка и оптовый минимум не участвуют в расчёте. Подробности обновления таблицы: [таблица и скорость, 28 сентября](docs/table-improvements-2026-09-28.md).

## Сбор цен

Подготовлен собственный серверный модуль Авито. «НН (Авито)» — группа отдельных столбцов продавцов, сопоставленных с теми же строками конфигураций и цветов. В каждой ячейке — минимальная цена этого продавца, ссылка на объявление, Trust, дата и раскрываемый аудит; дополнительные объявления остаются внутри ячейки своего продавца. Профили различаются по ID, даже если названия совпадают. Подтверждённый магазин сохраняет отдельные столбцы сайта и Авито. Колонки формируются только из реальных данных выбранной выдачи. 27.09.2026 сервер получил настоящую выдачу и карточку; первая проверенная карточка импортирована как частичный срез с исходным временем получения. Проверка обработчика фильтров затем получила 403. На dev включён почасовой таймер с шестичасовой паузой после ограничения; непрерывный полный сбор ещё не подтверждён. Сайт показывает состояние и время следующей допустимой попытки. Исследование, формулы, запуск и ограничения: [Авито НН](docs/avito-research.md). Без явного `AVITO_TRANSPORT=http` команда `npm run collect:avito` работает без сети.

Подключены BigGeek, Айфория, RifaStore, Technichno, iMobile, ReSale, Apple Store Нижний Новгород, Rebro Нижний Новгород, Madstore Нижний Новгород, Smart Device Нижний Новгород, AFM Нижний Новгород и Telegram-источник BSA (`@BigSaleApple`). iMobile обходится от каталога `/mac` до карточек MacBook и публикует каждый выбираемый вариант отдельно по цене без карты лояльности. ReSale читает публичный каталог Tilda с сайта `resale52.ru`, публикует каждый вариант памяти и цвета отдельно и помечает цены как розничные за наличный расчёт. Apple Store обходит все страницы каталога `nn.stores-apple.com`, проверяет полноту по общему числу карточек и публикует обычную розничную цену; более низкая условная цена при покупке гарантии не используется. Rebro обходит все страницы `nn.rebro-store.ru/catalog/mac/`, сверяет число карточек с итогом каталога и публикует текущие цены доступных MacBook и iMac, не принимая зачёркнутую обычную цену за актуальную. Madstore начинает с `/macbook`, обнаруживает все связанные категории и секции публичного Tilda-каталога, проверяет пагинацию и дубли, а в таблицу публикует явно обозначенную цену при оплате наличными. Smart Device обходит пять разделов каталога `/mac` (Air, Pro, Neo, iMac и Mac mini), проверяет полноту страниц Tilda и публикует актуальную цену каждого варианта за наличные в группе «НН». AFM читает все страницы каталога `afmcenter.ru/shop/mac`, публикует отдельные цены цветов за наличные, а отсутствующие характеристики Neo и iMac проверяет по карточкам. Варианты без цены учитываются отдельно и не получают цену другого цвета. Кнопка «Обновить цены» запускает общий сбор, включая Smart Device и AFM; почасовое обновление сохранено. BSA-коннектор принимает через Bot API посты канала и пересланные из него сообщения, хранит последний кэш вне публичных файлов и разбирает датированные прайс-листы MacBook Air, Neo и Pro. Используются только прайсы с датой не раньше текущего дня по Москве; веб-страница `t.me` и пользовательская MTProto-сессия не используются.

Telegram Business Connection даёт боту доступ только к выбранным личным чатам бизнес-аккаунта и не даёт доступ к подпискам аккаунта на каналы. Поэтому полностью автоматические `channel_post` от `@BigSaleApple` возможны только если владелец канала добавит бота в канал. Без этого официальный Bot API получает BSA-пост только после его пересылки боту. Bot API не предоставляет запрос истории чатов.

Токен хранится только на сервере в закрытом файле вне репозитория:

```bash
TELEGRAM_BUSINESS_BOT_TOKEN=123456:secret
TELEGRAM_BSA_CHANNEL=BigSaleApple
TELEGRAM_BUSINESS_WEBHOOK_SECRET=random-secret
TELEGRAM_BUSINESS_WEBHOOK_IP=135.106.220.39
```

Сервису нужно передать этот файл как `EnvironmentFile`. Его права должны оставаться `0600`; содержимое нельзя коммитить или выводить в логи. В dev используется защищённый webhook `https://dev.macbookbro.ru/api/telegram/bsa-webhook`. `TELEGRAM_BUSINESS_WEBHOOK_IP` необязателен и привязывает доставку Telegram к конкретному IPv4. Если webhook-секрет не задан, сервер использует long polling как резервный режим. Для разовой проверки polling без запуска веб-сервера доступен `npm run telegram:poll`.

Если хостинг не может напрямую соединиться с Telegram, `apps-script/telegram-relay.gs` работает как минутный polling-релей. В Script Properties задаются `TELEGRAM_BOT_TOKEN`, `DEV_WEBHOOK_URL` и `DEV_WEBHOOK_SECRET`, после чего один раз запускается `installTelegramPoller`. Релей забирает очередь через Bot API, пересылает обновление в защищённый dev webhook и только после успешного ответа сохраняет следующий `TELEGRAM_LAST_UPDATE_ID`; поэтому недоставленное сообщение не подтверждается и будет повторено.

Сервер автоматически собирает цены и ассортимент всех подключённых источников при запуске и каждый час. Открытый браузер не требуется. Таймер использует общую блокировку с Telegram-обновлениями. `AUTO_REFRESH_INTERVAL_MS=0` отключает встроенное расписание для сред с внешним таймером. В закупке дата прайса показывается как «Сегодняшний ценник», «Вчерашний ценник» или конкретная дата. Ручной служебный запуск:

```bash
LIVE=1 RETAILER=Technichno npm run build:data
LIVE=1 RETAILER=ReSale npm run build:data
LIVE=1 RETAILER='Apple Store' npm run build:data
LIVE=1 RETAILER=Rebro npm run build:data
LIVE=1 RETAILER=Madstore npm run build:data
LIVE=1 RETAILER="Smart Device" npm run build:data
LIVE=1 RETAILER=AFM npm run build:data
LIVE=1 npm run build:data
```

Состояние обновления показывает текущий источник и число завершённых источников. Отказ или неполный сбор одного магазина не удаляет сохранённые цены. Блокировка предотвращает одновременный запуск двух сборщиков; сетевые запросы и весь процесс ограничены таймаутами.

## Хранение и резервная копия

Источник истины — локальная SQLite с историей наблюдений. JSON является производным снимком. Неоднозначные цены и конфликты характеристик сохраняются для проверки; пропавшая из частичного сбора карточка не считается отсутствующей в продаже.

```bash
npm run backup
node scripts/backup.mjs /path/to/backup-directory
```

Копия содержит SQLite, каталог, требования и контрольные суммы. По умолчанию она сохраняется в `data/private/backups/`. Внешняя копия и регулярное расписание пока не настроены.

Сервер слушает `127.0.0.1`, раздаёт только разрешённые файлы и API. SQLite и закрытые данные из `data/private/` не публикуются. Текущий режим рассчитан на одного локального пользователя.

Служебная публичная выгрузка `npm run export:public` отделена от рабочей таблицы и содержит только утверждённые цены из отдельного контракта. Сейчас таких решений нет, поэтому она пуста. GitHub Pages не получает локальную мастер-базу. Внешняя публикация таблицы и Google Sheets в этой итерации не подключались.

Сравнительный сбор: 27,0 → 21,2 с; 12 источников успешны, Авито ограничен HTTP 403. Раздел использует действующий сборщик и часовое расписание; вход — существующие данные основного macbookbro.ru. Сайт заказов продолжает работать отдельно.

Результаты аудита и публикации 25.09.2026: [измерения, изменения и восстановление](docs/performance-audit-2026-09-25.md).

Браузер использует компактный `/api/table`; полный `/api/master` загружается при экспорте. Отдельный desktop-прайс больше не запрашивается. Готовые ответы кэшируются с проверкой изменений SQLite, файлы и снимки поддерживают ETag/304. На dev в Caddy включены `encode zstd gzip`. Фоновый сбор обновляет до трёх разных источников одновременно, сохраняя прежние ограничения внутри каждого магазина и общую блокировку.
