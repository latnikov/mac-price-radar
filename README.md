# Mac Price Radar

Внутренний парсер цен российского ритейла на MacBook с тем же принципом, что и AppleInsider Price Guides: одна нормализованная конфигурация, все предложения магазинов, и выделенная минимальная цена с ссылкой на магазин.

## Быстрый старт

```bash
npm install
npm run build:data
npm run dev
```

Откройте `http://localhost:4173/web/`. Для живого сбора из добавленных источников: `LIVE=1 npm run build:data`. Парсеры Technichno и RifaStore намеренно консервативны: для стабильной работы нужно добавить точные селекторы карточек после получения HTML каталога, а не угадывать цены из произвольного текста.

## Как добавить поставщика

Реализуйте `RetailerAdapter` в `src/adapters.ts`, верните `Offer` с моделью, чипом, RAM, SSD, экраном, ценой, состоянием и URL. Состояние `new` обязательно для попадания в минимум. Секретных поставщиков подключайте отдельным закрытым адаптером или загружайте их JSON/CSV в `data/incoming/`; не коммитьте доступы.

## Google Sheets

`apps-script/Code.gs` — привязанный к вашей таблице синхронизатор. В Apps Script вставьте код, замените `DATA_URL` на URL размещённого `data/cheapest.json`, запустите `syncMacPrices` и один раз `createHourlyTrigger`. Колонки совпадают с нормализованной схемой, поэтому будущие магазины добавляются без изменения таблицы.

## Самостоятельный хостинг

1. Создайте приватный GitHub-репозиторий и загрузите проект.
2. На VPS установите Node.js 20+, клонируйте репозиторий и выполните `npm install`.
3. Добавьте cron: `0 * * * * cd /opt/mac-price-radar && LIVE=1 npm run build:data`.
4. Раздайте каталог репозитория через любой статический веб-сервер. Самый простой вариант: `python3 -m http.server 4173 -d web` за Nginx; корень должен видеть и `data/` (например, Nginx location `/data/` на каталог проекта/data).
5. Для production лучше собрать Astro-фронтенд поверх этой же JSON-модели, а сборщик запускать отдельно. UI уже отделён от парсеров, поэтому миграция не затрагивает расчёт минимума.

## Ограничения MVP

Google-таблица по ссылке не была доступна для чтения из текущего окружения, поэтому структура сделана по описанной задаче и совместима с импортом строк. Перед production нужно получить экспорт исходной таблицы и сопоставить её названия колонок, а также добавить точные карточные селекторы/JSON-LD для Technichno и RifaStore.
