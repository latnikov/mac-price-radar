# Mac Price Radar

Внутренний парсер цен российского ритейла на MacBook с тем же принципом, что и AppleInsider Price Guides: одна нормализованная конфигурация, все предложения магазинов, и выделенная минимальная цена с ссылкой на магазин.

## Быстрый старт

```bash
npm install
npm run build:data
npm run dev
```

Откройте `http://localhost:4173/web/`. Перед этим выполните `npm run build:data`, чтобы создать `data/cheapest.json`. Кнопка «Обновить ценники» пересобирает каталог; актуальные цены появятся после подключения рабочих селекторов карточек магазинов. До этого `data/offers.json` содержит только seed-примеры и не должен считаться live-источником.

## Как добавить поставщика

Реализуйте `RetailerAdapter` в `src/adapters.ts`, верните `Offer` с моделью, чипом, RAM, SSD, экраном, ценой, состоянием и URL. Состояние `new` обязательно для попадания в минимум. Секретных поставщиков подключайте отдельным закрытым адаптером или загружайте их JSON/CSV в `data/incoming/`; не коммитьте доступы.

## Google Sheets

Синхронизация вынесена из Apps Script в Node.js: `SHEET_WEBHOOK=... npm run sync:sheet` отправляет `data/cheapest.json` во внутренний webhook. Так можно подключить Sheets API, Airtable, PostgreSQL или собственный endpoint без привязки парсера к Google Apps Script.

## Самостоятельный хостинг

1. Создайте приватный GitHub-репозиторий и загрузите проект.
2. На VPS установите Node.js 20+, клонируйте репозиторий и выполните `npm install`.
3. Добавьте cron: `0 * * * * cd /opt/mac-price-radar && LIVE=1 npm run build:data`.
4. Раздайте каталог репозитория через любой статический веб-сервер. Для проверки: `npm run dev`, затем откройте `/web/`.
5. Для production лучше собрать Astro-фронтенд поверх этой же JSON-модели, а сборщик запускать отдельно. UI уже отделён от парсеров, поэтому миграция не затрагивает расчёт минимума.

## Ограничения MVP

Исходная Google-таблица не была доступна для чтения из текущего окружения. Для production нужно сопоставить её колонки и добавить точные карточные селекторы/JSON-LD для Technichno и RifaStore.
