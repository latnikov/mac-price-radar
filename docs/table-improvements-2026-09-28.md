# Таблица магазинов и Telegram, 28 сентября 2026

Опубликовано на https://dev.macbookbro.ru/web/.

## Итоговый интерфейс

- Цены каждого магазина видны сразу в отдельных колонках. Порядок: модель, средняя по НН, рекомендация продажи, закупка, соседние магазины НН, Москва/РФ, продавцы Авито.
- Цвета и несовместимые комплектации представлены отдельными строками, без раскрывающихся групп. Пропущенные параметры могут объединяться только с единственным однозначным значением. Неизвестные параметры источника не переписываются.
- Средняя НН использует по одной свежей цене каждого магазина. Рекомендация продажи сохранена: 500 ₽ ниже минимальной сопоставимой цены доверенного магазина НН; существующие ограничения доверия сохранены для рекомендации.
- Убраны футер, cookie-баннер, подзаголовок, подсказка поиска и блок пояснений над таблицей.
- Удалены «запас», сводные карточки, переключатели «Есть запас»/«Нужна проверка», компактный вид и кнопка копирования ссылки.

## Скорость и повторы

Нормализация названий и объёма SSD, удаление повторных наблюдений по карточке/варианту/условиям, предпочтение более свежей цены даже при её повышении. Разные продавцы Авито остаются разными колонками.

По 30 строк на странице. Поиск и экспорт учитывают всю выборку. Снимок таблицы кэшируется по ревизии базы, ответы сжимаются gzip, неизменившиеся данные возвращают 304; повторный разбор JSON и отрисовка пропускаются.

Проверка опубликованной версии: 2292 предложения, 1183 строки после разделения несовместимых характеристик; первоначально отрисовываются 30 строк и 1516 элементов внутри tbody. Ранее контрольный снимок создавал 588 строк и 28628 элементов tbody. Это сравнение объёма начальной отрисовки разных снимков, а не обещание ускорения сетевой загрузки в фиксированное число раз.

## Telegram

- Автоматическое обнаружение каналов по числовому ID. В колонке используется название канала; «Дима» остаётся внутренним ID существующего источника «прайс от Л».
- Webhook и long polling запускают разбор нового прайса через общую очередь обновления. Полный почасовой сбор также включает обнаруженные каналы.
- Новые источники используют текстовый разбор MacBook и поддерживаемых строк iMac, публичные или приватные ссылки на исходные посты. Для недатированного прайса используется исходная дата сообщения.
- Повтор сообщения не обновляет возраст цены. Повторная доставка старой версии не отменяет правку. Новая цена одной комплектации заменяет старую даже при повышении.
- Фото/OCR и произвольные нестандартные форматы не добавлялись. Если текст не распознан, источник остаётся в колонках с явным сообщением об отсутствии распознанных цен.
- Кэш исходных сообщений остаётся закрытым. API таблицы публикует только описания источников и предложения, без данных отправителя или токенов.

Локально: 217 тестов основной системы и TypeScript успешно. После возврата рекомендации дополнительно прошли 23 связанных теста. Поиск M5 Pro дополнительно проверен пятью тестами: M5 Max и артикулы с окончанием M5 не подмешиваются. Серверная установка содержит только рабочие зависимости, поэтому TS-тесты и typecheck проверены локально.

Релиз: `/srv/mac-price-radar/releases/stores-20260928-JWuxSW`.

Перед установкой проверены контрольные суммы исходного кода. В релизе сохранены `files.txt`, `new.sha256`, `backup-files.txt`, `backup-code.tar.gz`, `tests.log`, снимок API и отданный HTML. Перезапускался только `mac-price-radar@dev`; сайты заказов и витрина не менялись. Последующее удаление отмеченных пользователем подписей опубликовано в `/srv/mac-price-radar/releases/ui-cleanup-20260928-cBGqdl`: футер и ссылка заказа, cookie-баннер с обработчиком, подзаголовок, поисковая подсказка, блок пояснений и дополнительный статус Авито над таблицей. Поиск расширен на освободившееся место. Проверены синтаксис, соответствие отданных файлов и живая страница: таблица загружается, ошибок JavaScript нет, средняя по НН и рекомендация остаются в начале. Резервная копия трёх изменённых файлов сохранена в этом релизе.

## Причины на бейджах и ReSale

Постоянная пониженная оценка ReSale удалена из расчёта рекомендаций, интерфейса и рейтинга связанных профилей Авито. Магазин участвует на общих основаниях. Вместо общей надписи «Нужно проверить» показана конкретная причина с процентом: отклонение вниз от среднего ориентира НН более чем на 5% либо разница между цветами одной комплектации. Процент округляется до одного знака после запятой, в подсказке указана цена сравнения. Проверены участие ReSale в рекомендации и рынке Авито, динамические исключения, процентные подписи и граничное значение 5%.
