# CRM с перепиской

Запрос владельца от 30.09.2026: собрать существующие прочитанные и непрочитанные диалоги двух профилей Авито и рабочего Telegram `@macbookbro`, отвечать из CRM, затем связать клиентов с карточками, сегментами и товарооборотом.

## Текущее состояние

Локально добавлен `/crm/inbox` в существующую CRM магазина. Доступ только владельцу и менеджеру, сохранена защита сессий и CSRF. Источники различаются по каналу и ID аккаунта; одинаковые ID диалогов разных профилей не объединяются. Переписка хранится в закрытой SQLite-базе магазина и не попадает в Git или публичный каталог.

Есть поиск по диалогам и сообщениям, фильтр аккаунта, пагинация, локальные заметки/сегмент и черновики. Импорт сохраняет исходный статус прочтения, если API его передало; отсутствие статуса показывается как неизвестное. Открытие диалога в CRM не меняет статус на площадке. Вложения пока представлены типом сообщения; скачивание/отправка файлов не реализованы.

Ручная отправка Авито включается серверным `STORE_INBOX_SEND_ENABLED=1` только с `AVITO_ACCOUNT_ID` (и для второго профиля `AVITO_2_ACCOUNT_ID`), совпадающим с идентификатором подключённого профиля. Отдельный черновик отправляется явным действием менеджера. При сетевой неопределённости повтор запрещён; результат нужно сверять на площадке. Никакие сообщения клиентам во время разработки не отправлялись. Постоянная синхронизация и привязка клиента к существующим заказам ещё не реализованы.

## Первый профиль Авито

Ключи находятся в игнорируемом `.env.avito` с правами 0600. Импорт: `npm run crm:import:avito`. На текущем аккаунте список доступен; получено 1100 диалогов и 1095 последних сообщений. Пагинация общего списка остановилась на пределе API, поэтому это не полный архив.

На Mac и на сервере `macbookbro` запрос полной истории вернул HTTP 402 с требованием подписки API мессенджера. Нужно подключить соответствующую опцию в кабинете Авито. Для полного архива также требуется выборка по объявлениям и проверка покрытия старых диалогов.

## Второй профиль Авито

У владельца пока нет второй пары ключей. Добавить её отдельно как `AVITO_2_CLIENT_ID` и `AVITO_2_CLIENT_SECRET`; нельзя использовать первую пару для другого аккаунта. Значения не записывать в документацию или коммит.

## Рабочий Telegram

Telegram на Mac открыт, но это не создаёт доступа CRM к аккаунту. Уже имеющийся Bot API обслуживает сбор цен, а не импорт всей клиентской истории.

Для полной облачной истории нужен Telegram API с авторизованной сессией рабочего аккаунта. Войти на https://my.telegram.org под рабочим номером, открыть **API development tools** и создать приложение. Сохранить полученные параметры в обычный текстовый файл `telegram.env` в «Документах»:

```env
TELEGRAM_API_ID=полученный_числовой_id
TELEGRAM_API_HASH=полученный_hash
TELEGRAM_ACCOUNT_USERNAME=macbookbro
```

Следующий этап — подготовить вход по QR/коду и импорт всей доступной облачной истории, включая архив, без отметки прочтения. Подтверждение входа выполняет владелец в рабочем Telegram; текущие данные приложения Telegram Desktop не извлекаются. Секретные чаты не входят в облачную историю.

Официальная документация: [получение API ID](https://core.telegram.org/api/obtaining_api_id), [диалоги аккаунта](https://core.telegram.org/method/messages.getDialogs), [история сообщений](https://core.telegram.org/method/messages.getHistory), [возможности Business-ботов](https://core.telegram.org/bots/features#business-bots).

## Дальнейший выпуск

Изменения пока локальные. Для выпуска нужно перенести закрытые подключения и базу в окружение магазина, добавить непрерывную синхронизацию, проверить отправку в согласованном тестовом диалоге и затем опубликовать CRM на `macbookbro.ru`. Сайт заказов и сборщик цен не должны получать ключи клиентской переписки.

## Реализация в клиентском сайте — 1 октября 2026

Клиентский сайт добавляет постоянное чтение источников, связь диалога с клиентом, сделки, задачи и обращения из кабинета. Реализован отдельный Telegram-процесс с входом владельца по коду/2FA и подписанным локальным импортом. Недостающие ключи второго Авито и авторизация Telegram остаются условиями подключения; код не заменяет эти права. Текущий тариф первого Авито ограничивает доступ к полной истории. Подробности запуска: [описание магазина](../storefront/README.md).
