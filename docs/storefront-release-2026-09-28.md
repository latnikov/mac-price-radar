Опубликовано: https://macbookbro.ru/ . CRM: https://macbookbro.ru/crm . Вход использует существующие учётные данные основного домена.

## Проверенный результат

- Сервис `macbookbro-shop` на loopback 4190; база отдельно от парсера и старых заказов.
- Главная возвращает HTTP 200; размер без сжатия 3615 байт. CRM без входа — 401, путь приватной БД — 404.
- `order.macbookbro.ru` и `dev.macbookbro.ru` продолжают работать. Предыдущее содержимое главного домена защищено на `/prices/`; старые `/web/*` перенаправляются туда.
- Источник цен — локальный `/api/table` работающего dev. Контрольная сумма общего модуля расчёта совпала с сервером: `cdbc69e19195290f753e56d002ef3e1d608fcc42fe8a277c171a27f42007e056`.
- При запуске получено 672 конфигурации, 75 свежих рекомендованных цен. Эти числа меняются при сборе и истечении срока цен.
- В рабочей базе 0 товаров и 0 заказов: тестовые записи не перенесены, чужие предложения не выданы за собственный ассортимент.
- Проверены 12 тестов магазина локально и на рабочей версии Node 24.21; 17 тестов старого сервиса заказов; 186 тестов основного проекта; проверка типов.
- В браузере проверены вход в CRM, создание карточки с рекомендованной ценой, публикация, корзина, оформление при ширине 390 px, подтверждение заказа и его появление в CRM. Использованы только локальные тестовые данные, без отправки сообщений и объявлений.
- Проверен бюджет <14 000 байт для каталога, карточки, корзины и оформления, включая предельные экранированные значения. Фото открываются отдельно. Полевые показатели загрузки из сетей покупателей пока не измерены.

## Не завершено

1. Реальное наполнение каталога: нужны собственные компьютеры, описания, фотографии, условия гарантии.
2. Рабочие Telegram-канал и бот; аккаунт, тип цены, организация и сопоставления МойСклад. Адаптеры проверены имитацией ответов, реальные отправки не выполнялись.
3. Подключение YML-ссылки из CRM к компании 65600128575 в Яндекс Бизнесе и проверка отражения изменений в Картах. Факт скачивания файла не подтверждает публикацию.
4. Авито: есть предварительный XML автозагрузки, рабочая выдача выключена. Категорийные поля, тариф, авторизация API и отчёты публикаций не проверены; переданные владельцем ключи в код не включены.
5. Подтверждённые сведения продавца и условия коммерческого запуска. Эквайринга нет; заказ предполагает связь и подтверждение, затем наличные или счёт.
6. Уведомления менеджеру по новым заказам нового магазина; сейчас заказ появляется в CRM.
7. Расширенные поля CRM (отдельные задачи, сроки, ответственные, платежи), автоматическая передача изменений статусов существующих документов МойСклад и перенос старых заказов.

Массовые запросы ограничиваются на сервере независимо от cookie. Полностью исключить чтение публичной цены или медленный распределённый сбор невозможно.
