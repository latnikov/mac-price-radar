# Редизайн dev — 26 сентября 2026

Опубликовано на https://dev.macbookbro.ru/web/ . Страница начинается с выбора Mac. Шапка и долларовый Excel-прайс убраны; Mac mini и Studio фильтруют рублёвые предложения магазинов. Обновлены карточки моделей, фильтры, таблица и мобильная компоновка.

Предупреждения источников, возраст закупки, расписание и ручное обновление собраны в один блок. Возраст определяется по validFrom (при отсутствии — fetchedAt), по московскому календарному дню. На данных dev показано «Закупочные цены — за вчера и ранее»: сохранены прайсы за 23–25 сентября. Технические сообщения о покрытии больше не выводятся пользователю; ошибки розничных источников остаются видимыми в понятной форме.

Проверки: 139 тестов и TypeScript прошли; после добавления проверки нового статического модуля повторно прошли 9 серверных тестов. В браузере проверены выбор Air, M5, 16 GB, сортировка, сброс, мобильная ширина 390 px. На опубликованном dev проверены итоговый статус, отсутствие ошибок JavaScript и Mac mini: 7 рублёвых предложений без долларовых колонок.
