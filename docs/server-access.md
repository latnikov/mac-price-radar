# Как подключаться к серверу MacBookBro

На твоём текущем Mac доступ уже настроен и проверен 29 сентября 2026 года.

## Подключение

1. Нажми **⌘ + Пробел**, напиши **Терминал** и открой его.
2. Вставь команду и нажми Enter:

   ```sh
   ssh macbookbro
   ```

3. После подключения появится приглашение с `root@gruzin`. Теперь команды выполняются на сервере.
4. Чтобы вернуться на свой Mac, введи `exit`. Сайты при этом продолжают работать.

Можно также дважды щёлкнуть файл `scripts/connect-server.command` в папке проекта. Он открывает то же подключение и поддерживает его при простое. Если macOS не разрешает запуск файла, используй команду выше в Терминале.

## Что где находится

GitHub хранит историю исходного кода: [latnikov/mac-price-radar](https://github.com/latnikov/mac-price-radar). На твоём Mac рабочая папка — `/Users/max/Documents/parser`.

Сайты работают на удалённом сервере `135.106.220.39` с именем `gruzin`. Три приложения запускаются как самостоятельные службы. Caddy принимает HTTPS-запросы и направляет их в нужное приложение.

| Сайт | Назначение | Папка на сервере | Служба |
| --- | --- | --- | --- |
| `dev.macbookbro.ru` | Парсер и таблица цен | `/srv/mac-price-radar/dev` | `mac-price-radar@dev` |
| `macbookbro.ru` | Витрина и CRM | `/srv/macbookbro-shop` | `macbookbro-shop` |
| `order.macbookbro.ru` | Сайт заказов | `/srv/macbookbro-orders` | `macbookbro-orders` |

`git push` отправляет код в GitHub. Для работающего сайта требуется ещё установить этот код на сервере и проверить результат. По твоему правилу «залей» означает весь цикл: проверка → коммит → пуш → публикация в нужном окружении → проверка сайта.

## Посмотреть состояние и журналы

После подключения узнать, работают ли приложения:

```sh
systemctl is-active mac-price-radar@dev macbookbro-shop macbookbro-orders caddy
```

Четыре ответа `active` означают, что все службы запущены. Подробности по парсеру:

```sh
systemctl status mac-price-radar@dev --no-pager
```

Последние 50 строк его журнала:

```sh
journalctl -u mac-price-radar@dev -n 50 --no-pager
```

Наблюдать за новыми строками:

```sh
journalctl -u mac-price-radar@dev -f
```

Нажми **Control + C**, чтобы закончить просмотр. Это останавливает только просмотр журнала.

Посмотреть файлы приложения:

```sh
cd /srv/mac-price-radar/dev
ls
```

Эти команды ничего не изменяют. Текущий доступ использует `root`, у которого есть полные права, поэтому команды удаления и перезапуска нужно выполнять осознанно.

## Как работает вход без пароля

Настройка хранится на твоём Mac в `~/.ssh/config`. Имя `macbookbro` сокращает адрес сервера и указывает нужный ключ. Секретный ключ находится в `~/.ssh/id_ed25519_macbookbro_selectel`; сервер узнаёт его публичную пару. Codex использует то же подключение, что и ты.

Ключ не нужно открывать, отправлять в чат или добавлять в GitHub. На другом компьютере одного имени `macbookbro` недостаточно: там нужно создать собственную пару ключей, добавить **публичный** ключ на сервер и настроить SSH. Текущее подключение при этом сохраняется.

Для передачи файлов с этого Mac можно открыть отдельный сеанс:

```sh
sftp macbookbro
```

Внутри него `ls` показывает удалённые файлы, `get имя-файла` скачивает файл в текущую папку Mac, `exit` закрывает соединение. Изменения кода лучше проводить через полный цикл «залей», чтобы сервер и GitHub оставались согласованы.
