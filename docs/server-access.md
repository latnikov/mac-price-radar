# Как подключаться к серверу MacBookBro

На твоём текущем Mac доступ настроен и проверен 2 октября 2026 года после переноса на Timeweb.

## Подключение

1. Нажми **⌘ + Пробел**, напиши **Терминал** и открой его.
2. Вставь команду и нажми Enter:

   ```sh
   ssh macbookbro
   ```

3. После подключения появится приглашение с `root@ams-1-vm-jhyj`. Теперь команды выполняются на Timeweb.
4. Чтобы вернуться на свой Mac, введи `exit`. Сайты при этом продолжают работать.

Можно также дважды щёлкнуть файл `scripts/connect-server.command` в папке проекта. Он открывает то же подключение и поддерживает его при простое. Если macOS не разрешает запуск файла, используй команду выше в Терминале.

## Что где находится

GitHub хранит историю исходного кода: [latnikov/mac-price-radar](https://github.com/latnikov/mac-price-radar). На твоём Mac рабочая папка — `/Users/max/Documents/parser`.

Сайты работают на Timeweb `201.34.144.229` с именем `ams-1-vm-jhyj`. Три приложения запускаются как самостоятельные службы. Caddy принимает HTTPS-запросы и направляет их в нужное приложение. `ssh macbookbro-timeweb` ведёт туда же. Прежний Selectel доступен через `ssh macbookbro-selectel`; его приложения и фоновые задания отключены, а Caddy временно пересылает запросы клиентов со старым DNS на Timeweb.

| Сайт | Назначение | Папка на сервере | Служба |
| --- | --- | --- | --- |
| `dev.macbookbro.ru` | Парсер и таблица цен | `/srv/mac-price-radar/dev` | `mac-price-radar@dev` |
| `macbookbro.ru` | Витрина; CRM на crm.macbookbro.ru | `/srv/macbookbro-shop` | `macbookbro-shop` |
| `macbookbro.ru/order/` | Форма заказов (старый домен перенаправляет) | `/srv/macbookbro-orders` | `macbookbro-orders` |

`git push origin dev` отправляет код в GitHub. Timeweb проверяет новые коммиты каждые две минуты, ждёт успешного CI для конкретного SHA, повторяет проверки у себя и публикует релиз. Проверить итог нужно по `/var/lib/macbookbro-ops/deploy.json` и HTTPS-заголовку `X-MacBookBro-Commit`. По твоему правилу «залей» означает весь цикл: проверка → коммит → пуш → публикация → проверка сайта. Процесс описан в [инструкции Timeweb](../deploy/timeweb/README.md).

## Посмотреть состояние и журналы

После подключения узнать, работают ли приложения:

```sh
systemctl is-active mac-price-radar@dev macbookbro-shop macbookbro-worker macbookbro-orders caddy
```

Пять ответов `active` означают, что все службы запущены. Подробности по парсеру:

```sh
systemctl status mac-price-radar@dev --no-pager
```

Последние 50 строк его журнала:

```sh
journalctl -u mac-price-radar@dev -n 50 --no-pager
```

Наблюдать за новыми строками:

```sh
journalctl -u mac-price-radar@dev -f
```

Нажми **Control + C**, чтобы закончить просмотр. Это останавливает только просмотр журнала.

Посмотреть файлы приложения:

```sh
cd /srv/mac-price-radar/dev
ls
```

Эти команды ничего не изменяют. Текущий доступ использует `root`, у которого есть полные права, поэтому команды удаления и перезапуска нужно выполнять осознанно.

## Как работает вход без пароля

Настройка хранится на твоём Mac в `~/.ssh/config`. Имя `macbookbro` сокращает адрес Timeweb и указывает ключ `~/.ssh/mbro_timeweb`; сервер узнаёт его публичную пару. Codex использует то же подключение, что и ты. Прежний ключ `~/.ssh/id_ed25519_macbookbro_selectel` используется только для сохранённого Selectel.

Ключ не нужно открывать, отправлять в чат или добавлять в GitHub. На другом компьютере одного имени `macbookbro` недостаточно: там нужно создать собственную пару ключей, добавить **публичный** ключ на сервер и настроить SSH. Текущее подключение при этом сохраняется.

Для передачи файлов с этого Mac можно открыть отдельный сеанс:

```sh
sftp macbookbro
```

Внутри него `ls` показывает удалённые файлы, `get имя-файла` скачивает файл в текущую папку Mac, `exit` закрывает соединение. Изменения кода лучше проводить через полный цикл «залей», чтобы сервер и GitHub оставались согласованы.

Полная актуальная схема служб, очистки, данных и восстановления: [инфраструктура платформы](platform-infrastructure.md).
