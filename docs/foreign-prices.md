# Зарубежные цены Mac

Отдельный лист `/web/foreign.html`, API `/api/foreign-prices`. Источник — раздел Mac AppleInsider (`https://prices.appleinsider.com/current-gen`) и обнаруженные в нём разделы моделей. Для каждой конфигурации читается только колонка Best Price, сохраняются исходная цена USD, конфигурация, ссылка и текст условий рядом с ценой. Рекомендованная цена Apple и размер скидки не используются.

Пересчёт: `Math.round(USD × (Google USD/RUB + 4))`. Источник курса — `https://www.google.com/finance/quote/USD-RUB?hl=en`. Курс не заменяется ЦБ, другим поставщиком или фиксированным числом. Доставка, налоги и пошлины не добавляются.

Общий почасовой сбор и ручная кнопка обновления включают AppleInsider. Отдельная кнопка листа обновляет только этот источник. Снимок хранится в закрытом `data/private/foreign-prices.json`, не включается в Git и не попадает в российскую закупочную/розничную аналитику. Обновление атомарное: при недоступном курсе, ошибке любого раздела или неизвестной разметке сохраняется последний успешный снимок со старым временем и новым статусом ошибки. Через четыре часа появляется отметка старой проверки.

## Ограничение проверки 30 сентября 2026

Прямые запросы с Mac и production-сервера получают HTTP 403 от AppleInsider (Cloudflare) и Google Finance. Обычная проверка AppleInsider в отдельном браузере также показала страницу проверки доступа. Поисковый просмотр доступен, но не является источником серверного сбора. Успешный живой сбор не подтверждён; сохранённых зарубежных цен при запуске нет. Тест HTML — модель контракта таблицы, а не реальная сохранённая разметка. После появления разрешённого доступа требуется проверить селекторы на реальном HTML и сравнить несколько конфигураций с сайтом. Пустой результат не заполняется придуманными ценами.

Проверки: `node --test test/foreign-prices.test.mjs test/server.test.mjs`, `npm test`, `npm run typecheck`. Покрыты формула, долларовые дробные значения, исключение скидок/рассрочки/отсутствующих товаров, конфигурации и условия купона, сохранение последнего результата при сбое, изоляция API и запуск через защищённый механизм обновления.
